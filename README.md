# Keyrow

macOS 原生数据库客户端：PostgreSQL、MySQL、MariaDB、SQLite、Redis、SQL Server、MongoDB、Elasticsearch / OpenSearch、DynamoDB，带 SSH 隧道和 TLS；连接、密码、密钥和设置保存在 iCloud，重装系统或换新 Mac 后自动恢复。

## 下载与安装

系统要求：macOS 27 及以上，Apple Silicon。

1. 下载 [Keyrow.zip](https://github.com/leadead/Keyrow-Releases/releases/latest/download/Keyrow.zip)（[所有版本](https://github.com/leadead/Keyrow-Releases/releases)）
2. 解压后把 Keyrow 拖入「应用程序」

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在 Keyrow 菜单中点「检查更新…」。

## 隐私

Keyrow 不采集、不上传任何数据。

本仓库只用于发布安装包，Release 页面的 Source code 压缩包里也只有这份说明。Keyrow 不开源：官方版本可免费下载使用，不得再分发或修改。
